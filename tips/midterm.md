Below are tips that are useful for completing the midterm exam.

## Creating Midterm directory

- Log into an interactive desktop session
- Open a terminal
- Make a midterm directory at your home directory with `mkdir midterm`

## Accepting Midterm Exam

Click the accept link below:

https://classroom50.org/PsuAstro410/410astro26/assignments/midterm-exam/accept

and follow the instructions. Do this before the midterm exam.

## Testing Midterm download and submission

Do the following steps before the midterm exam to ensure that you are able to access the shared Google Drive from which the Midterm will be posted. All students are responsible for testing their submission capabilities before the Exam.

- Open the terminal
- In the home directory, type `module load firefox`
- Launch firefox
- Log into your email
- Open google drive link for folder "Astro 410 Midterm Exam Fall 2026"
- Download `Astro410_Midterm_Exam_test.ipynb`. This file will likely be downloaded into your `Downloads folder`.
- Change directories to the downloads directory by typing into the terminal command line `cd Downloads`
- Move .ipynb file into midterm directory using `mv Astro410_Midterm_Exam_test.ipynb ../midterm`
- Open Midterm exam test with Jupyter Notebook or JupyterLab
- Run Command
- Submit assignment using usual git commands to the accepted Midterm Assignment

## Downloading Midterm exam on day exam taken

On day of exam, midterm exam will be posted in google drive folder "Astro 410 Midterm Exam Fall 2026" shortly before 9:05 AM. Repeat previous steps to submit your individual midterm exam.
